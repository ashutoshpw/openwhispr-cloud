# Start a project with the starter

Use this documentation when you need to get from a fresh clone to a working application without rebuilding the project foundation yourself.

## What do you need to do?

- **Run the project for the first time:** follow [Get the starter running](./getting-started).
- **Decide how people sign in:** use [Choose and configure authentication](../configure/authentication).
- **Add persistent data:** follow [Connect a database](../configure/database).
- **Locate the right code:** read [Find the code you need to change](../customize/project-structure).
- **Resolve a local setup issue:** start with [Troubleshoot local setup](../operate/troubleshoot).

Choose a top-level tab to continue with the task you are trying to complete.
