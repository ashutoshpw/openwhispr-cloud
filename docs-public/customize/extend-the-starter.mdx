# Extend the starter safely

## Finish initialization first

Run `bun run setup` before normal development. The generated auth provider and
`.env.local` configuration are prerequisites for the regular dev command.

## Put behavior at the right boundary

- Keep route-specific behavior in `apps/next-app`.
- Move reusable domain behavior into a `packages/*` workspace package.
- Keep database reads and writes behind `@repo/database` schemas/DALs.
- Use the package entry points and exports instead of importing implementation
  files across workspace boundaries.

## Validate a change

Run the focused app build and the relevant package checks:

```bash
bun run --filter @repo/next-app build
bun run lint
bun run format:check
```

If the change adds a schema, use the database migration workflow. If it adds a
public agent or integration endpoint, update the public contract and the
maintainer/security documentation together.
