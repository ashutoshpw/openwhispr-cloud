# Next.js 16 Starter Kit

This is a Turborepo monorepo for building full-stack Next.js applications with
Bun workspaces, authentication, PostgreSQL, Drizzle, and shared domain
packages.

Start with [Getting started](/start/getting-started), then choose an
authentication provider and connect a database. When you are ready to change
the code, use [Project structure](/customize/project-structure).

## What is included

- Next.js 16 App Router application in `apps/next-app`.
- Shared packages for auth, billing, analytics, database, durable execution,
  AI, MCP, and object storage.
- A one-time setup workflow that selects the authentication implementation.
- Optional Stripe, PostHog, Inngest, SEO/AIEO, and agent integrations.
