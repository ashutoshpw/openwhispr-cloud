# Dictate Once, Automate Everywhere with the API

Every dictation you take is structured text with a timestamp, a note, and metadata — raw material for automation. OpenWhispr Cloud exposes that material through a simple API: create an API key in the dashboard, and your scripts, cron jobs, and internal tools can search notes and pull transcripts without scraping anything. No fragile export flows, no copy-paste bridges.

For AI agent users, MCP access goes a step further. Point your agent at the OpenWhispr MCP server and it can search your notes semantically — ask for "the quarterly revenue discussion" and find the dictation where you said it, not just exact keyword matches. The agent sees only what your key allows, and revoking the key revokes the access instantly.

## Get started

API keys live in Dashboard → Settings. MCP configuration examples are in the docs, and local models still handle every word of the dictation itself.
